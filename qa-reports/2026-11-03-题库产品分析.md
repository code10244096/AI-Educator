# 题库产品分析与简化方案（2026-11-03）

## 现状问题（用户三点抱怨 + 截图核实）

1. **学科信息过载**：高中数学老师进入题库看到 16 个学科 Tab（含大学化学/管理学/经济学等完全无关学科）。虽然默认选中本学科，但视觉上仍是"全学科超市"。
2. **筛选层级冗余**：学科 Tab 区 + 学段下拉 + 搜索框三层筛选叠在页面顶部，学科 Tab 还折成两行，看起来像"两个子页签"，老师不知道该先点哪个。
3. **教学提示文案错位**：题目详情的「教学提示」实际显示的是数据来源与许可信息（"来源 C-Eval，许可 CC BY-NC-SA 4.0……"），对老师备课没有帮助，还引发"这内容能不能用"的疑虑。
4. **空目录**：部分学科（如科学 3892 题集中在小学）在老师自己的学段下无题，点了是空列表。

## 核心判断

题库的真正价值在**后端 RAG**（教案生成按学科+年级检索 27 万题，task-13 已上线），浏览页只是辅助入口。当前浏览页把"数据资产的全貌"直接摊给老师，违背了"按我的学科给我能用的题"这一直觉。**保留入口，但极简化**；若简化后反馈仍差，再考虑隐藏独立入口、只保留 RAG 隐式使用。

## 简化方案（本次实施）

面向"高中数学老师"的目标体验：打开题库 = 我的学科 + 我的学段 + 一个搜索框 + 题目列表。

1. 学科 Tab 区整体移除，页面标题改为「题库 · 数学」（本学科），不再出现任何其他学科信息；学科固定为教师任教学科（档案未填时回退数学，保留去设置页完善的提示）。
2. 学段下拉保留（默认用户学段），搜索框保留（模糊搜索已上线）。
3. 移除题目详情的「教学提示」区块（teaching_tips 不再渲染；来源/许可信息不属于教学场景）。
4. 空学科问题随学科 Tab 移除自然消失；本学科+本学段无题时显示明确空态文案。
5. 后端接口与 RAG 检索完全不动。

## 后续观察指标

- 题库页搜索使用率、搜索无结果率；
- 教案生成时 RAG 命中题数（已有 retrieved_questions_count）；
- 若题库页持续无人使用，下个版本隐藏入口，仅保留 RAG。
