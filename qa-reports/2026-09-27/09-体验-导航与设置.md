## 修改点

### EX-M-01　P1　窄屏用户按钮只剩一个字

| 字段 | 内容 |
| --- | --- |
| 现象 | 宽约 390 时，顶栏用户按钮只显示「老」和一个箭头，看不出是「老师」。730 宽左右能看到「老师」。点开菜单后仍有完整姓名和账号 `123456`。 |
| 建议改法 | 窄屏也显示姓名「老师」。头像里的一个字可以留着，但不要把姓名整段藏掉。顶栏按钮上不必再写账号。 |
| 疑似文件 | `frontend/src/components/Navbar.jsx` |

### EX-M-02　P2　学校空着，不知道要不要填

| 字段 | 内容 |
| --- | --- |
| 现象 | 个人资料里学校是空输入框，没有占位，也没有「选填」说明。账号下面有说明，学校没有。 |
| 建议改法 | 占位写成「选填，例如：某某中学」。不填也可以，不要在这次验收里保存。 |
| 疑似文件 | `frontend/src/pages/Settings.jsx` |

### EX-M-03　P2　修改密码时看不到自己打了什么

| 字段 | 内容 |
| --- | --- |
| 现象 | 当前密码、新密码、再次输入新密码都不能显示明文。登录页同一个眼睛按钮是有的。 |
| 建议改法 | 三个框都加上「显示密码 / 隐藏密码」，交互和登录页一致。不要在验收里提交新密码。 |
| 疑似文件 | `frontend/src/pages/Settings.jsx` |

### EX-M-04　P2　姓名可以改，但看起来和不能改的账号放在一起

| 字段 | 内容 |
| --- | --- |
| 现象 | 账号是灰的，并写明不能修改。姓名是白底，可以输入，下面没有任何说明。点「保存修改」就会改掉显示名。这次没有保存，姓名仍是「老师」。 |
| 建议改法 | 若显示名不允许改，把姓名改成和账号一样禁用，并写原因。若允许改，在框下写「这是显示名称，可以修改」，避免和旁边的账号搞混。 |
| 疑似文件 | `frontend/src/pages/Settings.jsx` |
