# 给开发 agent 的修改指导

日期：2026-10-23  
环境：本机已启动的前端 `http://127.0.0.1:3000`、后端 `http://127.0.0.1:8000`  
范围：公测教师端（小学 / 初中 / 高中 / 大学，多学科）是否真能用；管理员能否看到以往 token，以及能否下载已生成文件。  
界面复核：并行的界面走查没有留下结果。随后用已经登录的初中语文老师「甘宜欣」在 `http://127.0.0.1:3000` 把工作台、班级、批改、错题本、教案、设置点过一遍。没有新开批改或变式题。

## 结论

管理员**能**看到以往 token，也**能**下载已留存的生成文件，但默认打开用量页时会看到 0。教师端已经在登录时收集学段和学科，教案的课题示例和生成提示会跟着变；班级、批改、错题本仍按高中数学做。

先改两件事：用量页默认时间范围，以及把老师的学段学科接到班级、批改、错题本。不要改登录鉴权，教师访问用量接口已经是 403。

## 1. 用量页默认「7天」，历史消耗被滤掉

**现象。** 用量页一打开，总调用和总 tokens 都是 0。最近一次模型调用在 2026-10-08，今天是 2026-10-23，默认范围是最近 7 天，所以旧账全部被排除。

**实测（同一管理员会话，只改 `since`）。**

| 范围 | 调用次数 | 总 tokens | 日期 |
|---|---:|---:|---|
| 今天 | 0 | 0 | — |
| 7天（页面默认） | 0 | 0 | — |
| 30天 | 71 | 159178 | 2026-09-26、2026-09-27、2026-10-08 |
| 全部 | 71 | 159178 | 同上，起止 `2026-09-26T07:34:02Z` 至 `2026-10-08T07:19:52Z` |

默认值在 `frontend/src/pages/UsageStats.jsx` 的 `useState('7d')`。`rangeToSince('7d')` 会带上 `since`，后端按这个时间过滤。

**怎么改。**

1. 默认范围改成 `all`。页面上仍保留今天 / 7天 / 30天 / 全部。
2. 当前范围是 0、但全部历史不是 0 时，在总 tokens 卡片下写一句：所选时间内没有调用；全部历史共 N tokens（最早日期至最晚日期），点「全部」查看。不要只留一个 0。
3. 「今日额度」全是 0 是对的（当天还没人调用）。把它的标题维持为「今日额度」，不要让它看起来像历史总账。

**验收。** 管理员登录后直接打开 `/usage`，不点时间按钮，总 tokens 为 159178（或当时 `全部` 的实时数），能看到 2026-09-26 起的按日、按模型、按功能。点「今天」变为 0，并出现上面那句提示。

## 2. 以往 token 大多没有记到老师名下

**现象。** 全部范围内 159178 tokens 里，约 146555 记在「未归属」，账号 `123456` 只有 12623，其余教师账号是 0。71 条调用里 66 条日志没有 `task_meta.teacher_id`（早期脚本、评测、探测）。新调用在 `backend/llm/gateway.py` 里已经把 `teacher_id` 放进 `task_meta`，这条要保留。

**怎么改。**

1. 「按账号」里「未归属」改成「未记到老师名下」。说明写成：早期脚本或评测日志，没有教师 ID，不是某个老师的账单。
2. 不要为了补齐数字去猜测教师 ID。
3. 功能 `probe` 在「按功能」里会直接露出英文 slug。给它一个中文名（探测），或在管理页过滤掉 `probe` / `bench`，避免和老师的教案、批改混在一张账单里。模型名可以继续显示，这是管理页。

**验收。** 全部范围内仍能看到 159178 和未归属的数量；新产生的教案或批改调用出现在对应老师那一行，而不是未归属。

## 3. 生成文件可以下载，但下到的是 JSON

**已通过，不要改坏。**

- `GET /api/usage/records` 列出两个账号文件夹：`123456`（教案 1、批改 1）、`13900006666`（教案 1、批改 1）。变式题目前是 0，没有文件可下。
- `GET /api/usage/records/123456/archive` 返回 zip（3908 字节），内含 `lessonplan/lessonplan-1.json`、`grade/grade-550.json`。教案正文在 JSON 的 `body` 里，标题是「导数的几何意义」。
- `GET /api/usage/records/123456/lessonplan/lessonplan-1.json/file` 返回该 JSON 原文。
- `GET /api/usage/records/download?days=2026-09-27` 返回 zip，路径为 `2026-09-27/123456/lessonplan/...` 和 `.../grade/...`。
- `2026-10-18` 还有 `13900006666` 的两份留存。该账号不在当前用户表里，仍出现在「使用记录」里，这是对的（老师删了自己的页面记录，管理员这里还留着）。
- 教师请求 `/api/usage/summary` 和归档下载均为 403 `仅管理员可访问`；未登录为 401。保持。

**怎么改。**

1. 「使用记录」和「按日期」的下载按钮旁注明：下载的是留存 JSON，教案正文在 `body` 字段。管理员不需要先猜格式。
2. 单条「下载」对教案另给一份 `.md`（内容就是 `body`），批改给一份可读的 `.md` 或 `.txt`（学生、学科、得分、逐题对错）。原始 JSON 留作次要入口，现有 zip 接口可以继续。
3. 没有变式题文件时，界面已经显示「变式题 0」，保持即可。不要做空 zip。

**验收。** 管理员在用量页对 `123456` 点下载，得到的压缩包里能直接打开教案正文，而不是只看到一层 JSON。教师账号打开 `/usage` 仍被挡在外面，菜单里没有「用量统计」。

## 4. 学段和学科只接到了教案，班级、批改、错题本仍是高中数学

登录页和 `backend/routers/auth.py` 的 `STAGE_SUBJECTS` 已经支持小学到大学、多学科。工作台会显示「学段 · 学科」。教案课题示例来自 `frontend/src/utils/topicExamples.js`，生成角色来自 `backend/ai_client.py` 的 `generate_lesson_plan`：高中数学走「高三数学把关教师」，其他学段学科走「{学段}{学科}教师」。这些保留。

下面几处没有接上老师资料。后端班级接口其实接受任意 `subject` 和 `grade`（`backend/routers/classes.py` 只是默认「数学 / 高三」），限制在前端。

| 老师会做什么 | 现在的行为 | 改哪里 |
|---|---|---|
| 新建班级 | 年级只有高一、高二、高三；学科写死数学 | `frontend/src/components/ClassManager.jsx` 的 `GRADES` 和 `subject: '数学'` |
| 布置作业 | 标题示例是「导数综合练习」 | `frontend/src/pages/ClassData.jsx` 作业标题 placeholder |
| 上传批改 | 请求里的学科永远是数学，页面不能改 | `frontend/src/pages/HomeworkGrader.jsx` 约第 171 行 `subject: '数学'`；`frontend/src/utils/api.js` 的默认参数 `'数学'` |
| 批改提示词 | 知识点要求写成「高中数学知识点（如函数的单调性）」 | `backend/ai_client.py` 的 `grade_homework` 提示词 |
| 错题本筛选 | 默认学科数学，选项只有数学、物理、化学 | `frontend/src/pages/WrongNotebook.jsx` 初始 `filter.subject` 和 `<option>` |
| 改自己的学段学科 | 设置页只能改姓名和学校 | `frontend/src/pages/Settings.jsx` 的 `ProfileSection` |

**怎么改。**

1. 年级按学段给选项：小学一至六年级，初中初一至初三，高中高一至高三，大学用「本科」或让老师自己填年级。新建班级的学科默认等于 `user.subject`，允许改成该学段下的其他学科。保存时把选中的 `grade` 和 `subject` 传给现有创建接口，不要再写死。
2. 批改上传使用当前用户的学科，页面上显示「正在以「初中物理」批改」，并允许本次改学科。`grade_homework` 的知识点一句改成「本题考查的{学段}{学科}知识点」，公式要求只在数学、物理、化学出现；语文、英语、历史等不要强迫 LaTeX。
3. 错题本默认「全部学科」。若老师资料里有学科，默认选中该学科。选项用该学段的学科列表，并保留「全部学科」。不要只留数理化。
4. 设置页增加学段、学科，校验规则与登录页 `STAGE_SUBJECTS` 相同（小学不能选物理）。保存走已有的 `PUT /api/auth/me`。
5. 作业标题的 placeholder 按学段学科给一个例子，可复用 `topicExamples`。
6. `backend/jobs.py` 里大学学段检索题库时被改成「高中」。非数学本来就会跳过题库，数学的大学老师会被当成高中卷。大学数学不要改写成高中；没有对应题库就跳过检索，和现在的非数学一样。

**2026-10-23 界面已核对（初中语文 · 甘宜欣）。**

- 工作台标题是「甘老师，晚上好」，下面是「初中 · 语文」。教师菜单是工作台、我的班级、作业批改、错题本、教案、意见反馈、设置，没有「用量统计」。
- 新建班级弹窗：名称示例「例如：高一5班」，年级只有高一、高二、高三，没有学科。已取消，没有创建班级。
- 批改页标题仍是「AI 作业批改助手」，没有学科选择。
- 错题本标题仍是「AI 错题本管家」。学科下拉当前值是「数学」，选项只有全部学科、数学、物理、化学。
- 教案页「试试这些课题」是春、背影、木兰诗。已有一份完成的《木兰诗》全文欣赏教案，预览里是互文、排比和木兰的性格，不是高中数学。这条生成链路是好的，改班级和批改时不要改坏它。
- 设置页只有姓名、账号、学校和修改密码，看不到也不能改学段、学科。

**验收（再用另外三个身份看一遍界面，不必真的调用模型）。**

- 小学语文：新建班级能选一年级到六年级，学科默认语文；批改页显示语文；错题本默认不是数学；教案「试试这些课题」里有「秋天的雨」，没有「导数的几何意义」。
- 初中物理：班级年级是初一至初三，学科默认物理；批改学科是物理。
- 高中数学：班级仍是高一至高三、数学；教案示例仍是导数、三角函数一类。这条是现有行为，改完不能坏。
- 大学计算机：班级不再被迫选高一；批改学科是计算机；教案角色按大学计算机，而不是高三数学。

## 5. 不要动的部分

- 教师和管理员的隔离：用量接口教师 403、未登录 401。
- 留存目录 `backend/user_records/{账号}/lessonplan|grade|variant/`。老师在自己页面删除后，管理员这里仍保留。
- 教案已按老师的学段、学科切换示例和提示词角色。
- 体验额度只在「今日额度」里给管理员看具体数字，返回给老师的句子里不要写次数和 token 数（`backend/trial_quota.py` 已有这条约定）。

## 建议顺序

1. 用量页默认「全部」，空范围时提示去看历史（第 1 节）。
2. 班级、批改、错题本、设置接上学段和学科（第 4 节）。
3. 管理端下载给可读的 md，并说明 JSON（第 3 节）。
4. 未归属文案和 `probe` 中文名（第 2 节）。
