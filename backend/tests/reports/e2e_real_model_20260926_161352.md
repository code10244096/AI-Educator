# 导数的几何意义与切线方程

## 一、基本信息

- **课题名称：**导数的几何意义与切线方程
- **课时数：**1课时
- **学生基础：**中等
- **建议课时：**45分钟

---

# 二、教学目标

## 1. 知识与技能

1. 理解导数的几何意义：函数 \(y=f(x)\) 在点 \(P(x_0,f(x_0))\) 处的导数，表示曲线在该点处切线的斜率。
2. 掌握切线方程公式：
   \[
   y-f(x_0)=f'(x_0)(x-x_0).
   \]
3. 能根据函数解析式求指定点处的导数，并写出切线方程。
4. 能处理“过曲线上一点的切线”“过某点的切线”“切线斜率已知”等常见问题。

## 2. 过程与方法

1. 通过物理中的瞬时速度，理解“平均变化率趋近于瞬时变化率”的过程。
2. 通过割线逼近切线，建立导数与切线斜率之间的联系。
3. 通过“求斜率—找切点—写方程—检验”的步骤，形成规范解题习惯。

## 3. 高考常用技巧与难度

1. **基础难度：**求函数在指定点处的切线方程。
2. **中等难度：**求曲线上某点处的切线斜率、切线与坐标轴交点。
3. **常用技巧：**
   - 切线斜率为 \(f'(x_0)\)；
   - 切线平行于直线 \(y=kx+b\)，则 \(f'(x_0)=k\)；
   - 切线垂直于斜率为 \(k\) 的直线，则
     \[
     f'(x_0)=-\frac1k\quad(k\ne0);
     \]
   - 求切点时必须同时满足“在曲线上”和“满足斜率条件”。

# 三、教学重难点

## 1. 教学重点

1. 导数的几何意义。
2. 利用导数求曲线在某点处的切线方程。
3. 理解切线方程中的点必须是曲线上的切点。

## 2. 教学难点

1. 区分割线斜率与切线斜率。
2. 处理“切线过定点”“切线平行或垂直于已知直线”等综合问题。
3. 准确确定切点横坐标，避免只列斜率条件而漏解或增解。

# 六、教学过程

## （一）导入：从瞬时速度到切线斜率（5分钟）

### 1. 具体情境

一辆汽车的位移函数为：

\[
s(t)=t^2\quad (t\ge0).
\]

求汽车在 \(t=1\) 秒时的瞬时速度。

在 \(t=1\) 到 \(t=1+h\) 这段时间内，平均速度为：

\[
\frac{s(1+h)-s(1)}{h}
=\frac{(1+h)^2-1}{h}
=2+h.
\]

当 \(h\to0\) 时，平均速度趋近于：

\[
\lim_{h\to0}(2+h)=2.
\]

所以汽车在 \(t=1\) 秒时的瞬时速度为 \(2\)。

### 2. 教师引导

- 平均速度对应什么？
- 当时间间隔越来越小时，平均速度的极限表示什么？
- 在函数图像上，这个过程有什么几何意义？
